# Act Chat — Roblox Fantasy MMORPG

An early-stage fantasy MMORPG project being developed in **Roblox Studio**.

## What I'm building

The goal is to create a large multiplayer fantasy world where players can customise their characters, choose from different races and classes, explore, fight enemies, take on quests, and progress through dungeons.

Planned systems include:

- Character customisation, races and classes
- Combat and abilities
- Experience points, levels and progression
- Inventory and equipment
- Quests, enemies and dungeons
- Persistent player data
- A large explorable world

## Current status

**Early development / initial setup.** The Roblox Studio Baseplate project has been created. The game is **not playable yet**, and the systems above are plans rather than finished features.

This repository contains initial project documentation and starter Luau code. Roblox Studio integration and testing are still needed.

## Getting started

See [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md) for the planned Roblox Studio folder structure and steps to continue development.

The `src/` directory contains starter modules intended to be moved or synced into Roblox Studio as development progresses. These GitHub files do not automatically become part of a Roblox place.

## Development roadmap

1. Set up the Roblox Studio project structure.
2. Add shared configuration and an initial levelling system.
3. Create a basic player HUD and character customisation flow.
4. Prototype combat against a training enemy.
5. Add a first quest and reward flow.
6. Introduce persistent saving and multiplayer testing.
7. Expand into more classes, environments and dungeon content.
